## About the Project

Multiverse Girls: Opalium is an independent game project developed with Unity and C#.

The game is connected conceptually and technically to the wider Opalium ecosystem, which includes a web platform, user accounts, leaderboards, reward systems, Telegram automation, APIs, backend services, and digital integrations.

The purpose of this project was not only to create a playable game, but also to explore how a game can work as one component of a connected digital product.

## Repository Contents

This repository currently contains the public Unity WebGL build of Multiverse Girls: Opalium.

- `Build` — compiled Unity WebGL files
- `StreamingAssets` — assets loaded by the application at runtime
- `TemplateData` — Unity WebGL page resources
- `index.html` — browser entry point

Selected source-code examples may be added separately after removing private configuration, credentials, and project-specific secrets.

## Development Approach

The project was developed iteratively:

1. Design the gameplay or product feature.
2. Implement the feature in Unity and C#.
3. Test the behavior and identify edge cases.
4. Debug and improve the implementation.
5. Build the WebGL version.
6. Verify the project in a browser.
7. Publish the updated version through GitHub Pages.

AI-assisted development tools were used for research, code review, debugging, and exploring possible solutions. Generated suggestions were reviewed, tested, and corrected before being included in the project.
